# Fork workflow

Maintain changes in Tomas-M/skippy-xd. Do not submit further pull requests to the official felixfung/skippy-xd repository. Slax pins this fork by full commit and archive checksum in the sibling linux-live repository.

Labels use PangoXft. Font configuration uses Pango descriptions with ordered, comma-separated family names and a point size. Keep shaped layouts cached across redraws and use Pango for UTF-8 ellipsization.
